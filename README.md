완성된 두 개의 웹 프로젝트를 소개합니다. 도시의 인상을 재해석한 에디토리얼 웹과, 한 장면씩 펼쳐지는 모바일 청첩장을 통해 콘텐츠와 인터랙션이 만나는 방식을 탐구했습니다.

## World Design Capital Busan 2028

### 부산병: 다시 보고 싶은 디자인 도시

부산을 다녀온 뒤에도 다시 떠올리고, 다시 찾고 싶게 되는 감각을 에디토리얼 스토리텔링과 스크롤 인터랙션으로 풀어낸 웹 프로젝트입니다.

[Live Site](https://wdc-busan.pages.dev/) · [View Source](world-design-capital-busan/)

- 도시 이미지와 여행 감성을 결합한 콘텐츠 구성
- 사진과 타이포그래피를 활용한 반응형 에디토리얼 레이아웃
- 페이지의 흐름을 따라 이어지는 인터랙티브 스토리텔링

## Interactive Wedding Invitation

사진과 문장이 차례로 펼쳐지는 모바일 중심의 인터랙티브 청첩장입니다. Three.js와 WebGL 기반의 스크롤 이미지 전환, 화면 비율에 맞춘 사진 연출, 한국어 타이포그래피를 하나의 경험으로 구성했습니다.

[Live Site](https://20261012.pages.dev/) · [View Source](mobile-wedding-unrolling-invitation/)

- Three.js와 WebGL을 활용한 스크롤 인터랙션
- 화면 비율별로 조정되는 반응형 이미지 연출
- 모바일 환경에 맞춘 한국어 타이포그래피

## Built With

`HTML` · `CSS` · `JavaScript` · `Three.js` · `WebGL` · `GLSL` · `Cloudflare Pages`
